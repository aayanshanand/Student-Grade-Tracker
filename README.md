# Student Grade Tracker

A full-stack **Student Grade Tracker** built with **React.js** and **Java Spring Boot** to manage student grades and provide useful academic performance insights.

## 🚀 Features

* Add and manage student information
* Add and track student grades
* Calculate student average grades
* Identify highest and lowest grades
* View student performance through a simple React interface
* REST API communication between frontend and backend
* Full-stack architecture using React and Spring Boot

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/aayanshanand/Student-Grade-Tracker.git
cd Student-Grade-Tracker
```

### 2. Start the Backend

Open the `backend` directory in your Java IDE and run the Spring Boot application.

Make sure Java and Maven are installed and configured.

### 3. Start the React Frontend

From the project root:

```bash
npm install
npm start
```

The React application will start on the local development server.

## 🔄 How It Works

The application follows a client-server architecture:

```text
React Frontend
      │
      │ REST API
      ▼
Spring Boot Backend
      │
      ▼
Student Grade Data
```

The React frontend provides the user interface, while the Spring Boot backend handles application logic and API requests.

## 📊 Performance Tracking

The application processes student grades to generate useful performance information such as:

* Average grade
* Highest grade
* Lowest grade
* Individual student performance

This makes it easier to monitor and understand academic results.

## 🎯 Project Goal

The goal of this project is to build a simple full-stack application that demonstrates practical use of **React.js, Java, Spring Boot, REST APIs, and frontend-backend integration**.
